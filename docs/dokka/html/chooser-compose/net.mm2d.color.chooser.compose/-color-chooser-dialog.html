Color chooser dialog.

Parameters

onDismissRequest

callback for a cancellation or platform dismissal.

onConfirm

callback when the color is confirmed. The chosen color is passed as argument. Close the dialog from this callback; confirmation does not invoke onDismissRequest.

modifier

modifier for the dialog surface.

initialColor

initial color, converted to 8-bit sRGB. If Color.Unspecified, Color.Black is used.

withAlpha

whether to edit alpha. If false, previews and the chosen color are opaque, including when confirmed without editing. Disabling alpha discards transparency.

scrollEntireContent

whether the preview and controls may scroll together on short windows. When false, only palettes scroll vertically. When enabled, the HSV panel is reduced to keep a separate area available for scrolling back toward the top.

choosers

list of choosers to show. Default is Chooser.entries.

initialChooser

initial chooser tab to select. Default is Chooser.M2.

onColorChanged

callback invoked whenever the editing color changes in the dialog.

colors

colors used for styling tabs and sliders. See ColorChooserDefaults.colors.

shape

shape of the dialog.

containerColor

color of the dialog container.

tonalElevation

tonal elevation.

properties

dialog properties.

contentSpacing

spacing between content blocks in the chooser.

previewHeight

height of the preview area.

previewLabelStyle

text style of preview labels.

tabTextStyle

text style of tab labels.

sliderLabelStyle

text style of slider labels.

confirmButton

composable slot for the confirmation button, receiving the currently selected color. Default is a Button labeled "OK" calling onConfirm.

dismissButton

optional composable slot for the dismiss button. Default is a TextButton labeled "Cancel" calling onDismissRequest.
